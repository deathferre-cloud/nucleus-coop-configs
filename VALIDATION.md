## v1.1.1, 1 ноября 2026

Документация обновлена по завершённому восстановлению контроллеров в игровом чате. Базовый чат прочитал VR-014/VR-015 и итоговый приватный JSON: SteamRunning=true, XInput slots 0/1 Connected=true, ProfileHash=BaselineHash. Два PnP Xbox 360 и применение профилей подтверждены игровым чатом; пользователь сообщил, что оба применились. Личные журналы и данные лицензий не опубликованы.

Перезапуск jlserv восстановил два физических устройства. Повторная активация имеющегося Lifetime access пользователем сняла последующий отказ проверки лицензии. Обычное применение и закрытие Steam отдельно не помогли. Причины исходных отказов не доказаны; новый игровой тест после этого восстановления не заявляется. Код, маппинг, патчи и установленные файлы не менялись.

Проверены ссылки и якоря всех трёх HTML-страниц, синтаксис неизменённого JavaScript и визуальная отрисовка нового раздела. В браузере при узком окне нет горизонтального переполнения; новые FAQ находятся поиском, открываются, скрываются при отсутствии совпадения и возвращаются после сброса поиска. Контрольные суммы архива и опубликованных страниц сверяются с локальными файлами.

### Переносимая адаптация

- Проверены хеши всех файлов приватной передачи, источник обработчика v6 и атрибуция Vlxst.
- Рабочие пути заменены на BaseDirectory; аппаратные и личные ID исключены, профили обозначены как reference-only.
- Патч применён к чистому официальному v6 в изолированной папке, помощник и общий код собраны штатным csc .NET Framework.
- Повторное применение к изменённому обработчику отвергнуто до изменения целей.
- Искусственная ошибка копирования после применения патча восстановила четыре прежних целевых файла побайтно.
- Полный немодифицированный блок подготовки portable handler исполнен реальным установленным Jint: два игрока, исходные пустые массивы/объекты/неизвестные поля сохранены, выбор звука переживает повторную запись, исходный файл не меняется. Попытка писать прямо в него отвергнута.
- Инструмент ссылок проверен на план без изменений, создание, чтение/запись, повторный запуск, отказ от совпадения с Steam ID, неправильной геометрии, обычного каталога и ссылки на другую цель.
- Ошибка создания второй ссылки откатывает только первую новую ссылку. Undo не удаляет целевые файлы, скрытые файлы и пустые папки; ранее существующие чужие ссылки остаются.
- Проверки установщика и ссылок выполнены в Windows PowerShell 5.1 и PowerShell 7. Ошибка чтения карты в 5.1 исправлена до публикации.
- Проверены запрет повторного запуска/переназначения при активной игре, защита резервного копирования и сохранение content/userprofile.json с игровыми ярлыками.
- Полный игровой запуск публичной адаптации на другом ПК не выполнялся. Fixture-проверки и работа локальной версии указаны отдельно.

### Документация

Для DST и V Rising подготовлены отдельные полные HTML-гайды. В каждом повторены необходимые общие шаги и есть своё оглавление, ежедневный чеклист, поиск по проблемам, тема и печать. Главная страница даёт выбор игры. Проверены HTML-ссылки, уникальные ID, синтаксис JavaScript и визуальная отрисовка. В настоящем браузере обе страницы прошли переключение темы, чеклист и сброс, поиск и пустой результат. На узком экране нет горизонтального переполнения. Перед выпуском проверяются отсутствие приватных данных и SHA256 каждого файла архива.

### Оставшиеся ограничения

- Физическое Bluetooth disconnect/reconnect внутри игры не проверено.
- V Rising standalone dedicated server Yes! не проверен; проверенная схема Default/No!, private world, SteamIPv4 и LAN выключен.
- Причины первой LAN-попытки с тайм-аутом и внутреннего зависшего соединения после crash не установлены. Чистый перезапуск того же мира помог.
- В DST агент отдельно не проводил персонажа через вход в пещеру. Проверены соединённые серверы Master/Caves и пользовательский игровой результат.

### Переносимый комплект

Проверки выполнялись в отдельной тестовой папке с исходным официальным обработчиком DST v15 и синтетическим профилем. Рабочая установка и сохранения этой проверкой не изменялись.

- Все PowerShell-скрипты прошли разбор штатным парсером Windows PowerShell.
- C#-исходники DesktopBridge v5, диспетчера окон и AudioCheck успешно собраны компилятором .NET Framework с библиотеками Nucleus 2.4.2.
- Установщик применил патч к исходному v15, создал адресную резервную копию и локальную конфигурацию. Преобразование двух SteamID в account ID проверено на известных синтетических значениях.
- Контрольный файл в saves остался побайтово неизменным.
- Повторная установка на уже изменённый обработчик отвергнута до изменения целевых файлов.
- В тесте принудительной ошибки копирования все пять существующих целевых файлов автоматически восстановлены с исходными SHA-256.
- Патчированный обработчик и JavaScript обеих HTML-страниц прошли node --check.
- Реальный Jint из Nucleus проверил переносимый BaseDirectory, чтение JSON с BOM, строки account ID, Path.Combine и длину CLR-массива, используемые обработчиком.
- AudioCheck запущен рядом с NAudio и обнаружил активные аппаратные аудиовыходы. Игровые аудиосессии проверялись ранее в рабочем сеансе.
- JSON-файлы разобраны; HTML проверен на повторяющиеся ID и несуществующие внутренние ссылки.
- Главная страница и аудиораздел отрисованы в Edge и визуально проверены. В узком headless-viewport 492 px измеренная ширина содержимого не превышала viewport. Это не отдельный тест на телефоне.
- Из публичного комплекта исключены реальные endpoint/controller ID, локальные пути владельца, токены, активация, игровые сохранения, бинарные файлы программ и сырые журналы.
- manifest.sha256.json фиксирует исходные файлы этой версии. Сам manifest, build и .git в него не входят.

### Ограничения на момент v1.0.0

- Полный запуск переносимого комплекта на другом компьютере и с другим оборудованием. Тестовая установка не заменяет эту проверку.
- Переход персонажа через вход в пещеру отдельно агентом. Подтверждены работа серверов и пользовательский игровой результат.
- Выключение и повторное включение Bluetooth-наушников внутри активной игры без перезапуска клиента.
- V Rising в игре: два клиента, сеть, ввод, аудио, сохранения и повторный запуск.
- Автоматический Start-Coop.ps1 из публичного комплекта в полном игровом сеансе. Локальный запуск и эквивалентное применение профилей reWASD проверены; переносимый скрипт проверен синтаксически.

Отчёт фиксирует выполненные проверки, а не обещание совместимости любых версий программ и устройств.
