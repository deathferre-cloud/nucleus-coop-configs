# Проверка подготовки V Rising через Jint

Verify-VRisingSettings.cs проверяет весь блок подготовки настроек из патчированного обработчика, а не только отдельный CLR-помощник.

1. Создайте отдельный временный fixture-каталог. Не используйте рабочую установку как базовую папку тестового EXE.
2. Соберите VRisingSettings.dll через tools/Build-VRisingSettings.ps1 и скопируйте его в fixture/setup.
3. Поместите рядом с будущим EXE Jint.dll и Newtonsoft.Json.dll из своей установки Nucleus, не публикуйте эти бинарники.
4. Соберите тест штатным csc .NET Framework с references на Jint.dll и Newtonsoft.Json.dll; EXE должен находиться в корне fixture.
5. Передайте EXE два аргумента: папка библиотек установленного Nucleus и путь к патчированному V Rising.js.

Тест создаёт только синтетические данные под собственной базовой папкой. Он исполняет немодифицированный блок через настоящий Jint, проверяет два независимых файла, пустые массивы/объекты, неизвестные поля, сохранение Sound.Driver при повторной записи, аргументы отдельных путей и запрет записи в исходный файл. Он не запускает игру, мост ввода или сервер.

Проверки установщика, отказов, инъекции ошибок и junction проводились отдельно в временных fixture-каталогах под Windows PowerShell 5.1 и 7. Результаты и границы проверки приведены в VALIDATION.md.
