03

Настройка с чистого листа

  1. Подготовьте обычную игру.

    Установите DST в Steam, один раз запустите её обычным способом и проверьте работоспособность. Обычные Steam-сохранения оставьте на месте. Для совместной игры будем использовать отдельный каталог Nucleus.

  2. Распакуйте Nucleus в собственную папку.

    Например, C:\Games\NucleusCoop. Не помещайте его внутрь игры или Program Files. Используйте официальный архив и 7-Zip. Запускайте Nucleus с рабочей папкой, равной его каталогу.

  3. Подготовьте оба экрана.

    Windows → Параметры → Система → Дисплей. Нажмите «Определить», задайте «Расширить эти экраны», перетащите прямоугольники согласно расположению на столе. Поворачивая монитор на кронштейне, также смените его ориентацию в Windows на альбомную.

  4. Подключите оба контроллера и обе пары наушников.

    Сделайте настройки из двух следующих разделов. Убедитесь, что Windows видит два независимых геймпада и два активных аудиовыхода.

  5. Получите обработчик DST.

    Добавьте игру в Nucleus через Hub и укажите установленный dontstarve_steam_x64.exe из bin64. Публичный патч рассчитан на обработчик v15. При другой версии не применяйте его вслепую.

  6. Создайте свой профиль и установите дополнение.

    Назначьте собственные экраны, контроллеры и аудио в профиле Nucleus, сохраните его. Затем закройте Nucleus и выполните установку из раздела 07.

Пути из нашего компьютера не нужно повторять. Везде, где встречается {NucleusRoot}, используйте вашу папку. Endpoint ID и reWASD device ID тоже будут своими.

04

Два Steam Controller через reWASD

Первичная настройка

  1. Установите reWASD с официального сайта. Если обновление требует перезагрузку, выполните её.
  2. Включите оба Steam Controller. Каждый должен отображаться подключённым, без серого состояния.
  3. Импортируйте файл Steam Controller to Xbox 360.rewasd.
  4. Выберите первый физический контроллер внизу окна. Выберите профиль «Nucleus Co-op DST» и конфигурацию «Steam Controller to Xbox 360».
  5. Нажмите жёлтую кнопку «Применить на Слот 1». Повторите для второго физического контроллера.
  6. Контроллеры должны оставаться независимыми. Не объединяйте их в одно виртуальное устройство.
  7. В Nucleus проверьте появление двух значков геймпадов и назначьте по одному каждому игроку.

Если геймпады пропали

  1. Сохранитесь и закройте игру, затем Nucleus.
  2. Убедитесь, что оба контроллера включены и подключены к этому ПК.
  3. В reWASD выберите первый контроллер → тот же профиль → «Применить на Слот 1».
  4. Выберите второй контроллер и нажмите ту же кнопку.
  5. Откройте Nucleus заново и выберите сохранённый профиль. Дождитесь Profile ready!.

Если второй контроллер серый, переподключите его. Для проверки можно использовать USB-кабель с передачей данных.

В нашем сетапе именно повторное применение профиля к обоим устройствам возвращало два Xbox 360 в Nucleus.
Как автоматизировать применение и использовать свои геймпады

В reWASD щёлкните правой кнопкой по каждому устройству и скопируйте его device ID. В конфигурации скопируйте путь к файлу профиля через Open file location. Заполните controllerIds и rewasdProfile в setup.local.json.

Скрипт Start-Coop.ps1 применяет профиль каждому ID отдельно. Для двух обычных XInput-контроллеров без reWASD задайте "controllerIds": []. Их назначение в Nucleus всё равно нужно проверить.

Не включайте параллельно ещё одну схему Steam Input/GlosSI для этих же устройств: сначала оставьте один понятный источник виртуальных контроллеров. В этой конфигурации таким источником служит reWASD.

05

Каждому собственные наушники

Player1

Окно 1 → выход 1

В нашем примере: Headphones (2- OpenSwim Pro by Shokz). Прямой стереовыход Windows, назначенный AudioInstance1.

Player2

Окно 2 → выход 2

В нашем примере: Headphones (OpenSwim Pro by Shokz). Другой endpoint ID, назначенный AudioInstance2.

Определите физические пары один раз

  1. Подключите первую пару Bluetooth-наушников через Windows. Проверьте её обычным тестом звука.
  2. Запишите название и endpoint ID через Get-Devices.ps1. Пометьте саму пару как Player1.
  3. Подключите вторую пару, повторите тест и пометьте её как Player2.
  4. С обеими включёнными парами выберите разные выходы в аудионастройках сохранённого профиля Nucleus.
  5. Используйте стереовыход A2DP. Если Windows показывает отдельный Hands-Free/гарнитурный выход, не выбирайте его для этой схемы игрового звука.

Просто выбрать одни наушники устройством Windows по умолчанию недостаточно: тогда оба окна могут получить один выход. Назначение должно быть отдельным для каждого экземпляра.

Если у вас уже работает VoiceMeeter

В исходной системе оба Shokz были выбраны в VoiceMeeter как WDM. Они оказались заняты эксклюзивно, и игры не могли воспроизводить звук. Рабочее исправление: переключить только эти аппаратные выходы на MME.

  1. Вверху справа в Hardware Out откройте список A1. Выберите вашу первую аппаратную пару в разделе MME.
  2. Для A2 выберите вторую пару, также MME. В нашем примере A1 соответствует Player2, A2 соответствует Player1.
  3. Сохраните конфигурацию VoiceMeeter через Menu → Save Settings. Остальные привычные маршруты не меняйте без необходимости.
  4. Оба игровых процесса в Nucleus направьте прямо в соответствующие наушники. Не назначайте обоим один общий VoiceMeeter Input.
  5. После изменения MME сохраните мир и полностью перезапустите игровые клиенты. Звуковой движок уже запущенной игры может не восстановиться сразу.

MME здесь выбран для совместного доступа с играми. Это проверенное решение конкретного конфликта, а не требование ко всем устройствам. Документация режимов VoiceMeeter.

Наушники выключили и включили во время игры

Лучший порядок: сначала включить обе пары, затем запускать Nucleus. Если пара отключилась, подключите её снова и подождите несколько секунд. При необходимости в VoiceMeeter выберите Menu → Restart Audio Engine.

Дополнение отслеживает доступность выходов и повторно задаёт маршрут, но физическое отключение и включение Bluetooth внутри игры ещё не проверялось. Если звук не вернулся, сохранитесь и перезапустите оба клиента. После удаления сопряжения и повторного добавления устройства может понадобиться заново выбрать endpoint в профиле.

06

Свой профиль в Nucleus

  1. Один монитор на одного игрока.

    В раскладке выберите по полной области каждого монитора. Перетащите первый геймпад на первый экран, второй на второй. Если экран вертикальный, сначала исправьте ориентацию в Windows.

  2. Сохраните назначения.

    Включите использование XInput Index для этой схемы reWASD. Дайте профилю понятное имя, например «Два монитора, два геймпада». Автозапуск оставьте выключенным, чтобы проверить назначения перед PLAY.

  3. Настройте звук внутри профиля.

    В Audio включите Custom settings и задайте разные устройства для AudioInstance1 и AudioInstance2. Сохраните профиль. Глобальные Default не заменяют загрузку этого профиля.

  4. Проверьте профиль перед запуском.

    Нажмите именно на его название в правом верхнем списке. На экранах должны стоять Player1 и Player2, сверху должно появиться Profile ready! Затем нажмите PLAY один раз и дождитесь обоих окон.

В games/dst/profile.reference.json лежит образец настроек. Его нельзя импортировать как готовую привязку чужих устройств. Профиль, созданный через интерфейс Nucleus, содержит ваши реальные экраны, контроллеры и локальные идентификаторы игроков.

07

Установить наши дополнения

Нужны установленный Nucleus 2.4.2, его официальный обработчик DST v15, два сохранённых назначения, Git и Windows PowerShell. Все команды выполняются из папки скачанного репозитория. Модификации применяются только после проверки совместимости патча.

  1. Скачайте ZIP нужного релиза репозитория и распакуйте его.
  2. В Steam Workshop подпишитесь на русский языковой пакет и Russian Font. Дождитесь загрузки.
  3. Скопируйте setup.example.json в setup.local.json. Укажите свои пути, два reWASD ID и файл сохранённого профиля DST.
  4. Закройте игры и Nucleus. Сделайте локальный снимок настроек.
powershell -NoProfile -File .\tools\Backup-Local.ps1 -NucleusRoot "C:\Games\NucleusCoop" -Destination "D:\CoopBackups"
powershell -NoProfile -File .\tools\Install-DST.ps1 -Config .\setup.local.json

Установщик проверит патч, соберёт DLL из исходников, сохранит адресные копии изменяемых файлов и создаст локальную конфигурацию путей. Он не переносит Steam-сохранения и не меняет ваш аудиопрофиль. Резервная копия находится в setup\backups\дата-время.

После установки запустите клиентов. Если новый клиент ещё не реагирует на свой геймпад, включите устройство Xbox 360 в настройках управления этого клиента и примените выбор. В каждом окне в «Моды → Клиентские моды» включите локальные Russian Language Pack и Russian Font, примените изменения и перезапустите. Убедитесь, что главное меню русское. Подробные шаги игры: гайд DST.

Получить названия и идентификаторы аудиоустройств
powershell -NoProfile -File .\tools\Get-Devices.ps1 -NucleusRoot "C:\Games\NucleusCoop"

Для проверки фактических аудиосессий после установки доступна утилита {NucleusRoot}\AudioCheck.exe: передайте ей два endpoint ID в кавычках. С флагом --test перед ID она подаст один сигнал в первом выходе и два во втором. Запускайте из папки Nucleus, рядом с NAudio.dll.

Команда Get-Devices только читает экраны и активные аудиовыходы. Ничего не отправляет в интернет. Идентификаторы из результата сохраняйте у себя.

Ярлык запуска и ярлыки возврата окон

Создайте ярлык для powershell.exe с аргументами ниже. Замените абсолютные пути на свои. Скрипт сначала применит оба профиля reWASD, затем откроет Nucleus в правильной рабочей папке.

-NoProfile -File "D:\nucleus-coop-configs\tools\Start-Coop.ps1" -Config "D:\nucleus-coop-configs\setup.local.json"

Для возврата запущенных игр создайте отдельный ярлык: объект {NucleusRoot}\setup\NucleusWindows.exe show. Для скрытия используйте аргумент hide, для переключения toggle. Эта утилита работает с обработчиками, в которых установлено наше дополнение и сохранён порядок трёх custom hotkeys.

09

Если что-то пошло не так

Оба окна звучат в одних наушниках

Убедитесь, что выбран сохранённый профиль с разными AudioInstance1/2 и установлена DLL v5. В ранней версии при закрытии второго клиента мог сохраняться его маршрут для первого. v5 проверяет принадлежность окна процессу.

После исправления назначения полностью перезапустите игру. В нашем тесте Windows уже показывала правильные назначения, но запущенный FMOD продолжал играть в прежнем выходе до перезапуска. Проверяйте фактический звук обоих окон по очереди.

Звука нет совсем, хотя Windows видит наушники

Подключите обе пары до запуска. Если VoiceMeeter использует эти выходы как WDM, смените именно их на MME. Сохраните настройки и перезапустите игры. Ранее эксклюзивный захват вызывал AUDCLNT_E_DEVICE_IN_USE (0x8889000A).

Не сбрасывайте весь микшер и все устройства Windows ради одного приложения. Сначала проверьте выбранные два выхода и громкость.

Не определился один или оба геймпада

Закройте сеанс. reWASD → первый контроллер → нужная конфигурация → «Применить на Слот 1». Затем второй контроллер → та же конфигурация → «Применить на Слот 1». Повторно загрузите профиль Nucleus. Серый контроллер сначала нужно подключить физически.

Обе игры стали английскими

После прерванной загрузки DST может выключить моды. В каждом клиенте включите Russian Language Pack и Russian Font в клиентских модах, примените и перезапустите. Дождитесь полного главного меню.

В нашем обработчике исправлен controller_popup: вопрос о геймпаде больше не принуждается при каждом запуске. Раньше остановка на этом диалоге оставляла boot_modindex в состоянии loading, и следующий запуск отключал русификацию.

Мышь или клавиатура заблокирована

Нажмите Ctrl+F10. Дополнение освобождает захват ввода внутри Nucleus и скрывает окна. Повторное нажатие возвращает игры. Старые утилиты, которые только сворачивали окна снаружи, для этой задачи не подходят.

Если горячая клавиша не работает, проверьте наличие дополнения в текущем обработчике. Для другой игры его нужно интегрировать отдельно.

Error loading Nucleus settings

Закройте окно ошибки и запустите Nucleus из настроенного ярлыка с рабочей папкой самого Nucleus. В нашем случае прямой запуск из чужого каталога вызывал ошибку чтения настроек, а правильный запуск восстанавливал работу без удаления Settings.ini.

Если ошибка остаётся, сохраните копию текущего файла и проверьте конкретный параметр. Не удаляйте сохранения или всю установку.

Dedicated Server Failed To Start или не запускаются пещеры

Посмотрите client_log.txt и серверные журналы Master/Caves. Проверьте, что защитное ПО разрешает клиент и dedicated server в bin и bin64, а Controlled Folder Access не блокирует папку сохранений. Настройки защиты меняйте адресно по инструкции производителя.

Для проверки отключите посторонние серверные моды. Русификация и шрифты в этом сетапе клиентские. Сохраните резервную копию мира перед экспериментами. Официальная диагностика Klei.

Второе окно маленькое или пропал чат

Ctrl+F7 переключает второе окно между полным монитором и 75% его ширины и высоты. При 1920 × 1080 уменьшенный размер равен 1440 × 810. Новый запуск возвращает полный размер. Если Nucleus ещё расставляет окна, дождитесь окончания запуска, затем нажмите клавишу.

Полная история изменений →

У каждого релиза есть тег Git и архив файлов. В CHANGELOG записываем проблему, причину, исправление и проверку. Статус каждой игры хранится отдельно. Подготовленный патч не помечаем как проверенную игру.

Перед обновлением

  1. Сохраните мир и закройте игры и Nucleus.
  2. Скопируйте папку saves отдельно. Она содержит прогресс и не входит в публичный снимок.
  3. Сделайте приватный снимок настроек через Backup-Local.ps1. Сохраните экспорт VoiceMeeter через его меню и свой профиль reWASD.
  4. Установите обновление и проверьте две игры, звук, ввод, язык и повторный запуск.

Как откатиться

Закройте сеанс. Верните обработчик и связанные файлы setup из адресной копии setup\backups\дата-время. Карта restore-map.json показывает исходные пути и какие файлы существовали до установки. Для полного возврата конфигурации используйте приватный локальный снимок; сохранения мира восстанавливайте только осознанно, чтобы не потерять более свежий прогресс.

Публичный snapshots/2026-10-30 содержит обезличенный образец, версии и контрольные суммы. Это переносимый снимок конфигурации, а не архив купленных программ или игровых файлов.
